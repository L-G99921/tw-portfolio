EnergyGrid Usage API

The EnergyGrid Usage API is the read API behind the EnergyGrid app and partner web portals. It returns the consumption, budget, and insight data customers see, and every call is made as the signed-in customer, not as the utility.

The PowerBox API moves data from the utility to EnergyGrid. The Usage API reads it back for one customer.

Audience​

Developers building partner mobile apps or white-label web portals that show energy use to customers.

Authentication​

Exchange a utility identity token for an EnergyGrid customer token with POST /Customer/login. Send the returned token as Bearer <token> on every other call. A token only reads data for the customer it belongs to. For the full handshake, see Configure authentication in the integration guide.

Base URL​

https://api.energygrid.example/usage/v1

Conventions​

  • Content type. application/json.
  • Granularity. Usage endpoints take a granularity parameter. Read the valid values from GET /MetaData/granularitytypes instead of hard-coding them.
  • Currency and units. Money is in the customer's billing currency. Energy is in the meter's unitOfMeasure, usually kWh for electricity.
  • Errors. Errors follow RFC 7807 problem details, with content type application/problem+json.

Try it in the browser​

Every operation page has a Send API Request panel. The hosts in this spec don't exist, so the site answers those requests in your browser with a simulated server built from this spec. Use any value as the bearer token.

About this sample​

The contracts reflect a realistic customer-facing usage API for a residential energy platform. EnergyGrid is fictional, and the hostnames don't resolve.
